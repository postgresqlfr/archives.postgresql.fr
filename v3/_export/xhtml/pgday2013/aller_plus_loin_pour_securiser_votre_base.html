Une description courte

La gestion des utilisateurs et de leur mots de passe est assez simpliste dans PostgreSQL. Cette présentation montrera une extension permettant d'aller plus loin dans la sécurité des utilisateurs : nombre limité de saisie d'un mot de passe, nombre limité de connexions échouées, etc.
