Expérience du 3ème type

Grégoire HUBERT, fondateur gérant de PragmaFabrik.

Bio:
Utilisateur de PHP et de Postgresql depuis le XXème siècle, le parcours professionnel de Grégoire HUBERT va l'emmener des premières SS2L aux web agencies en passant par l'hébergement. Auteur de Pomm, il fonde PragmaFabrik en 2013.

twitter: @chanmix51

Titre de la conférence: “Expérience du 3ème type”

description courte:
À quoi servent et comment utiliser les types composites, les tableaux, les objets ? Cette conférence propose de faire un retour d'expérience sur les services rendus par les types de PostgreSQL.

description longue:
Les développement web adressent aujourd'hui des problématiques métier de plus en plus complexes. PostgreSQL est parfaitement outillé pour répondre à ces problématiques mais de l'autre coté, les frameworks de développement ne proposent pas souvent d'en utiliser les fonctionnalités. L'utilisation des types de PostgreSQL est pourtant un atout majeur dans la structuration des données. À quoi peuvent bien servir HStore, LTree, les types composites ? Comment utiliser les fonctionnalités objet de PostgreSQL ? Cette conférence sera l'occasion de faire un retour d'expérience sur les services rendus par la richesse des types de PostgreSQL.
