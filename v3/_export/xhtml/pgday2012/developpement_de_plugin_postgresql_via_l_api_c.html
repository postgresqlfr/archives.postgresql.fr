Développement de plugin PostgreSQL via l'API C

Nom : Olivier Courtin

Employeur : Oslandia

Titre : Développement de plugin PostgreSQL via l'API C

Description :

Quelles sont les enjeux, étapes, réflexes et méthodes permettant de développer un plugin PostgreSQL en C ?

Parce que l'écriture de fonctions en Pl/PgSQL est pratique, mais dans certains contextes, peut s'avérer limitant en terme de performances, (typiquement sur des traitements un tantinet massif).

Parce que vous avez peut être aussi besoin d'interfacer la puissance du SQL de PostgreSQL avec des fonctionnalités issues d'une librairie C/C++ externe.

Ou tout simplement parce que vous êtes curieux de savoir un peu mieux comment l'API plugin de PostgreSQL fonctionne, et que la lecture de la doc officielle, sur ce sujet, ne vous suffit pas.

Pour toute ces raisons, cette présentation aura à coeur de dessiner les principes clés d'une création d'un nouveau plugin PostgreSQL, illustrations (comprendre code) à l'appui.

Des techniques de développement et de débug seront aussi, bien entendu, abordées.
