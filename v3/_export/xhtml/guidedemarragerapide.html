Mise à jour

Les guides de démarrage rapide ont été initiés par Florence Cousin pour la version 8.3 de postgreSQL et repris par Julien2512 à partir de la version 9.1. L'objectif est bien sûr de suivre l'évolution des versions de PostgreSQL !

Le PDF fourni est actuellement réalisé avec LibreOffice au format ODT, accompagné de simples captures d'écran, et destiné aux OS :

  • Debian/Ubuntu
  • RHEL/CentOS
  • Windows

Le document ODT et sa version PDF sont actuellement stockés sur le dépôt github suivant : https://github.com/julien2512/guide_du_debutant_postgresql
