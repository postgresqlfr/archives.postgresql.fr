Afin de pouvoir “dumper” facilement toutes vos fonctions, il suffit de les regrouper dans un schema séparé, ce schema fonctionnera comme un namespace. Pour appeler les fonctions, soit vous utilisez les noms complets (schema.function) soit vous changez au niveau de la session ou du server le “search_path”.

Pour récupérez toutes vos fonctions en une fois, faites 

pg_dump -n schema
