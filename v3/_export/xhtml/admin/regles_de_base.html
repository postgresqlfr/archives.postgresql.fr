Règles de base

Quelques principes à respecter pour ne pas se marcher sur les pieds entre admins et éviter les blocages (liste non exhautive) :

  1. Ne jamais rebooter un serveur pendant le week-end ou un jour férié
  2. En cas d'intervention sur un serveur, se connecter sur la chan #postgresqlfr-admin
  3. Toute installation doit être documentée dans le wiki
  4. Toute modification du fichier /etc/sudoers ou tout ajout/retrait dans le groupe sudo doit être approuvé sur la liste admin@pgfr
