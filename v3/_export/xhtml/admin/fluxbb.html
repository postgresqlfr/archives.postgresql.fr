Modifications effectuées

Ajout de l'attribut « nofollow » sur tous les liens utilisateurs dans le but d'éviter les nombreux messages de spam/bot :

Fichier /var/www/forum.postgresql.fr/include/parser.php, ligne 683.

Avant : 

return '<a href="'.$full_url.'">'.$link.'</a>';

Après : 

return '<a href="'.$full_url.'" rel="nofollow">'.$link.'</a>';
