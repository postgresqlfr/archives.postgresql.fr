PG Day France 2017

Les discussions de préparation se font sur la liste http://listes.postgresql.fr/cgi-bin/mailman/listinfo/pgdayfr2017. Inscrivez-vous pour participer !

Les grandes lignes

Voici un descriptif rapide de l'événement:

  • Date : 8 juin 2017
  • Lieu : Toulouse
  • Salle : CIC Météo-France
  • Durée : 1 jour (9h- 17h30)
  • Fréquentation attendue : 150-200 personnes
  • Tarif : tarifs
