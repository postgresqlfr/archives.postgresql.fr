PG Day France 2018

Les discussions de préparation se font sur la liste pgdayfr@listes.postgresql.fr.
Inscrivez-vous pour participer !

Les grandes lignes

Voici un descriptif rapide de l'événement:

  • Date : 26 juin
  • Lieu : Marseille
  • Salle : théâtre Joliette
  • Durée : 1 jour (+ réunion GTE la veille)
  • Fréquentation attendue : 150-200 personnes
  • Tarif : tarifs
  • Contenu : programme

Feuille de route

⇒ Utilisation de framaboard : https://pgday-france.framaboard.org/ (Cf Carole pour la création de compte)

  • septembre : Lancement du projet
  • octobre-janvier : Recherche de lieu
  • novembre : bilan prévisionnel
  • janvier : Constitution du comité programme
  • janvier : lancement de l'appel à orateurs
  • janvier : recherche traiteur
  • février : ouverture des inscriptions
  • début mars : fin de l'appel à orateurs
  • fin mars : annonce du programme
  • avril : commande de goodies
  • mai : impressions
