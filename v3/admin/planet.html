Planet

→ http://planete.postgresql.fr

Installation

Installé sur Babar par Damien Clochard le 2 avril 2008.

Logiciel utilisé : http://www.planetplanet.org

Commentaires :

  • Le DocumentRoot est : /data/www/fr/postgresql.fr/planete
  • Le fonctionnement est simple : un script python récupère les fils RSS et génère du HTML statique.
  • Le cache est mis à jour toute les heures /etc/cron.hourly/planet
  • La configuration se fait dans /var/www/planete.postgresql.fr/pgfr/config.ini :
    • [http://...]
    • name = Le Nom
